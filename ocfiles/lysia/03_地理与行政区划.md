# 卷三 · 地理与行政区划

> 本卷落实《00_总纲与一致性基准》的**决定 2、3、5**：利西亚为**南北分裂**（北 PRL、南利西亚联邦），铁墙**东西走向**横贯国土中部，PRL 在**东南角保有艾瑞斯海出海口**。旧稿"西与联邦接壤"等表述一律作废，以本卷地图为准。

---

## 一、全球地理总览

厄尔塔地表由**五块主要大陆、一片群岛与四大洋**构成，另有一处对利西亚至关重要的内海。

| 陆地单元 | 位置 | 特征 |
|---|---|---|
| 埃律西昂大陆（Elysia） | 北半球，横跨温带 | 最大、最重要，主舞台大陆，利西亚在此 |
| 南方大陆（Meridiana） | 跨赤道至南半球 | 热带与温带兼备，殖民历史深厚 |
| 东方大陆（Oriontia） | 东大洋以东 | 独立古老文明圈，隔海相望 |
| 西陆群岛（West Archipelago） | 西大洋中部 | 火山岛弧，航运与战略要冲 |
| 北极冰盖 / 南极冰盖 | 两极 | 冰封大陆，人类活动稀少 |

**四大洋**：西大洋、东大洋、南大洋、北方冰洋。
**内海**：艾瑞斯海（Eiris Sea），位于埃律西昂大陆南部，地中海式的半封闭海域，连接东西航路。

---

## 二、埃律西昂大陆总览

埃律西昂大陆是厄尔塔最大、人口最多、文明最发达的大陆，东西跨度极大，自西向东依次分布着不同气候与文明圈：

```
（西） 西大陆 ── 中央利西亚地区 ── 东部大平原 ──（东）
        西大洋岸                        东大洋岸
              （南）南部地中海区（艾瑞斯海）
              （北）北部极地区（斯卡拉山脉以北）
```

大陆地势总体**西高东低、中北多山、南部临海**。三条东西向气候带（北部寒温带、中部温带、南部亚热带/地中海式）与一条纵贯南北的利西亚河，共同决定了利西亚"中部枢纽"的战略地位。

---

## 三、西大陆（Westland）

- **位置**：埃律西昂大陆西半部，濒临西大洋。
- **气候**：受西大洋暖流影响，温带海洋性气候，冬暖夏凉、降水充沛。
- **地形**：西部为高峻的西陆山脉（板块俯冲造山带，火山地震活跃），东部为缓丘与肥沃平原。
- **主要势力**：西大陆合众国（United States of Westland）——资本主义超级大国、全球霸主，以及一批高度发达的工业国。
- **对利西亚的意义**：西大陆是利西亚联邦的靠山与 PRL 的头号对手，其"自由繁荣"形象对铁墙东侧民众形成持续的意识形态吸引力。

---

## 四、中央利西亚地区（本世界观舞台）

### 4.1 总体位置

位于埃律西昂大陆中部，是东西南北交通的十字路口。以利西亚为核心，涵盖若干周边小国与缓冲地带。

### 4.2 利西亚的地形骨架

| 方位 | 地形 | 说明 |
|---|---|---|
| 北 | 斯卡拉山脉（Skara Mountains） | 海拔 1000–3000 米，天然屏障与资源宝库（铁、煤、铀） |
| 中 | 卡利斯托平原与中部丘陵 | 土壤肥沃，"国家的粮仓"，工业城市与交通枢纽密布 |
| 南 | 艾瑞斯海沿岸平原 | 狭长沿海平原与天然良港（艾瑞斯港） |

**水系**：利西亚河（Lycia River）发源于斯卡拉山脉，纵贯中部平原，注入艾瑞斯海，是利西亚的经济命脉与航运干道。

**战略地位**：控制利西亚即可控制大陆中部的东西陆路通道与南北水路，这正是利西亚自古以来成为列强争夺焦点、并被一分为二的地理根源。

## 五、南北分裂与铁墙（权威地理格局）

> 本卷核心设定，修正旧稿矛盾。

### 5.1 分裂格局

利西亚全境被**东西走向的铁墙**横贯中部，一分为二：

| 区域 | 国家 | 首都 |
|---|---|---|
| 铁墙以北（利西亚北部） | 利西亚人民共和国（PRL） | 卡利斯托北城 |
| 铁墙以南（利西亚南部） | 利西亚联邦（Lycischer Bund） | 南卡利斯托（卡利斯托南城） |

### 5.2 PRL 四邻（权威）

| 方位 | 接壤 | 说明 |
|---|---|---|
| 北 | 斯卡拉山脉（诺瓦联盟） | 与诺瓦联盟成员国接壤 |
| 南 | 铁墙（利西亚联邦）+ 艾瑞斯海 | 西南段为铁墙，**东南段临艾瑞斯海（出海口）** |
| 东 | 东部大平原（诺瓦联盟） | 广袤平原 |
| 西 | 西大陆方向缓冲地带 | 与西大陆合众国势力范围相邻 |

### 5.3 利西亚联邦四邻（权威）

| 方位 | 接壤 | 说明 |
|---|---|---|
| 北 | 铁墙（PRL） | 与 PRL 对峙 |
| 南 | 艾瑞斯海 | 濒临艾瑞斯海 |
| 东 | 伊利安共和国 + 艾瑞斯海 | 艾瑞斯海沿岸 |
| 西 | 西大陆合众国方向 | 接受西大陆保护 |

### 5.4 出海口问题（决定 3 的落实）

铁墙并非笔直贯穿利西亚全境，而是在**东部沿海前终止、折向**。因此：

- **PRL** 在东南角保有艾瑞斯海的一段海岸线（艾瑞斯海州、艾瑞斯港所在）。
- **利西亚联邦** 占据艾瑞斯海西南段海岸线。
- 两国**同濒艾瑞斯海**：PRL 占东北段，联邦占西南段，海上生命线在艾瑞斯海内形成对峙。

> 这样解决了"PRL 既南面有联邦、又拥有艾瑞斯港与海军"的矛盾——艾瑞斯港位于 PRL 东南角的出海口，是 PRL 唯一的海上门户。

### 5.5 卡利斯托的分割（决定 5 的落实）

铁墙将卡利斯托分为**北城（PRL）与南城（联邦）**。利西亚河纵贯卡利斯托市区，铁墙沿利西亚河两岸及城区南北中线修筑，渡口与桥梁全部封堵，仅留少数军事检查站。北城为 PRL 首都，南城为联邦核心城市。

## 七、PRL 行政区划（权威）

利西亚人民共和国全国划分为 **1 个直辖市 + 9 个州**，州下设县（Kreis），县下为乡镇、集体农庄与厂矿区。

| 行政区 | 首府/中心 | 定位与特点 |
|---|---|---|
| 卡利斯托直辖市（Kalisto） | 卡利斯托（北城） | 首都，政治、文化、教育中心，被铁墙南北分割 |
| 北斯卡拉州（Nord-Skara） | 斯卡拉要塞 | 北部山地，边防、矿业、军事要塞 |
| 黑隼山州（Falkenland） | 隘口镇 | 黑隼隘口所在，父亲维克多阵亡地，军事要地，铀矿 |
| 中平原州（Mittelgau） | 瓦伦堡 | 全国粮仓，铁路枢纽，卫国战争重灾区 |
| 钢铁城州（Eisenstadt） | 钢铁城 | 重工业与军工中心，污染重 |
| 煤都州（Kohlenburg） | 煤都 | 煤炭开采与火电集中 |
| 西界州（Westmark） | 铁墙哨城 | 铁墙沿线，边防与监控前沿 |
| 东平原州（Ostgau） | 东埠 | 东部平原，与诺瓦联盟的陆路贸易通道 |
| 南丘陵州（Südhügel） | 牧城 | 中部偏西丘陵，畜牧与森林 |
| 艾瑞斯海州（Eirisküste） | 艾瑞斯港 | 南部沿海，港口、渔业与海军基地（PRL 唯一出海口） |

## 八、城市详设

### 8.1 卡利斯托（Kalisto）

- 人口约 200 万，全国唯一大都会，被铁墙一分为二（北城 PRL / 南城联邦）。
- **北城分区**：
  - 行政区：先锋党总部、人民大会堂、各人民委员会机关，戒备森严。
  - 中央广场：国庆日阅兵与群众集会场所，象征国家权威。
  - 工业区：红星工厂等重工业企业沿利西亚河与铁路线分布。
  - 工人住宅区：灰色混凝土板楼，配给商店、集体食堂点缀。
  - 文化区：卡利斯托大剧院、博物馆、图书馆、卡利斯托军事学院、隼翼学院、国家孤儿院。

### 8.2 钢铁城（Eisenstadt）

- 北部山地钢铁工业中心，高炉林立、烟囱蔽日，空气污染严重。
- "工人阶级"与工业力量的象征，环境问题最突出的城市。

### 8.3 煤都（Kohlenburg）

- 中部丘陵煤炭基地，矿坑、火电厂与矿工社区构成主体，矿工文化浓厚。

### 8.4 艾瑞斯港（Eiris Port）

- 南部沿海最大港口，兼具贸易与军事功能，PRL 唯一出海口。
- 相对开放，是接触外界、进行有限对外贸易的窗口，也是海军基地。

### 8.5 瓦伦堡（Valenburg）

- 中部平原交通节点小城，铁路枢纽 + 小型军工厂，靠近铁墙。
- 娜塔莉娅的童年故乡，卫国战争末期遭联邦轰炸几乎夷为废墟，战后重建。

### 8.6 斯卡拉要塞（Skara Fortress）

- 北部边境军事堡垒，扼守斯卡拉山脉通道，象征国家防御。

### 8.7 黑隼隘口（Black Falcon Pass）

- 斯卡拉山脉关键隘口，连接北方盟友，设有军事要塞。
- 卫国战争中的血腥战场，父亲维克多在此英勇牺牲。

## 九、交通网络

| 类型 | 说明 |
|---|---|
| 铁路 | 以卡利斯托为枢纽的放射状铁路网，连接工业城市、矿区与边境；瓦伦堡是重要节点 |
| 公路 | 有限硬面公路网，优先保障军事运输 |
| 水路 | 利西亚河内河航运 + 艾瑞斯海海运，是南北物流补充 |
| 航空 | 少量军用机场，民航极不发达，出国需严格审批 |
| 铁墙影响 | 铁墙切断南北交通，卡利斯托铁路与地铁被分段封闭，首都物理分裂成为国家分裂的具象缩影 |

## 十、区域差异与方言

### 10.1 区域差异

- **南北差异**：南部沿海相对温暖、开放；北部山地寒冷、军事化、封闭。
- **城乡差异**：首都与工业城市相对发达，乡村生活艰苦、物资匮乏。
- **工业区 vs 农业区**：重工业区污染重、配给紧张；农业区粮食相对充足但生活单调。

### 10.2 三大方言

| 方言 | 使用区域 | 特点 |
|---|---|---|
| 北部山地方言（斯卡拉方言） | 斯卡拉山脉 | 最古老，保留大量古词 |
| 中部标准语（卡利斯托标准语） | 官方/教育/广播 | 娜塔莉娅使用 |
| 南部沿海方言（艾瑞斯方言） | 沿海 | 受海洋贸易影响，外来借词多 |

## 十一、生态与物种

### 11.1 利西亚三大生态带（由北到南）

| 生态带 | 位置 | 特征与物种 |
|---|---|---|
| 北部山地针叶林与高山草甸 | 斯卡拉山脉 | 雪松、云杉、冷杉；黑隼、狼、棕熊、马鹿 |
| 中部温带阔叶林与草原 | 卡利斯托平原 | 已开垦为农田（小麦、黑麦、甜菜、土豆） |
| 南部地中海式灌丛与沿海湿地 | 艾瑞斯海沿岸 | 硬叶灌丛、盐沼、湿地，候鸟驿站，渔业丰富 |

### 11.2 特有与重要物种

- **黑隼（Black Falcon）**：民族图腾，大型猛禽，栖息于斯卡拉山脉悬崖与中部平原，是引导亡魂的"星辰使者"。
- **北方雪松（Nordzeder）**：建筑与造船用材。
- **中部黑麦（Mittelroggen）**：黑面包原料。
- **艾瑞斯海银鱼（Eiris-Silberfisch）**："黑隼烤鱼"原料。
- **家畜**：中部黑猪、山地绵羊、役用牛。

### 11.3 矿产与资源分布

| 矿产 | 主要分布 | 用途 |
|---|---|---|
| 铁矿 | 北斯卡拉州、黑隼山州 | 钢铁工业原料 |
| 煤矿 | 煤都州、北斯卡拉州 | 火电与炼钢 |
| 铀矿 | 斯卡拉山脉深处 | 核能与核计划（高度机密） |
| 铜、铅、锌 | 黑隼山州 | 有色金属工业 |
| 稀土 | 南丘陵州 | 高新技术与军工 |
| 森林 | 北部山地、中部丘陵 | 木材、造纸 |
| 渔业 | 艾瑞斯海 | 食物与经济 |

### 11.4 环境问题

- 重工业污染：钢铁城、煤都烟尘废气，酸雨频繁。
- 重金属污染：河流与湖泊工业废水污染，影响饮用水与渔业。
- 过度开采：矿产资源掠夺式开采，矿区生态退化、地面沉降。
- 保护区：斯卡拉山脉"黑隼自然保护区"与艾瑞斯海海洋公园，是仅存生态庇护所。
