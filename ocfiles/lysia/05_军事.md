# 卷五 · 军事（利西亚人民军与完整武器设定）

> 本卷所有装备型号均为架空名称，与任何现实武器无对应关系。口径、弹重、射程、威力、穿深、装甲等为客观物理参数，按内部自洽原则设计。
> 命名体系见《00_总纲与一致性基准》。诺瓦联邦体系（动物名+序号）、利西亚国产体系（隼科图腾）、西大陆体系（掠食动物+数字）。

---

## 一、军队总览

### 1.1 基本概况

| 项目 | 内容 |
|---|---|
| 名称 | 利西亚人民军（Lycischer Volksarmee，简称 **LVA**） |
| 成立 | 1949 年，与共和国同期 |
| 规模 | 常备军约 30 万，预备役约 50 万（含民兵） |
| 最高统帅 | 总书记（名义），实际由国防部与总参谋部指挥 |
| 政治属性 | 高度政治化，忠于利西亚人民先锋党（LPVP） |
| 军事学说 | 以守为主、重点防御、北守南防；以装甲突击为反击核心，以防空反舰为屏障 |

### 1.2 指挥体系

```
总书记（最高统帅）
        │
   国防委员会 / 中央政治局军事组
        │
   国防部 ──── 总参谋部
        │         │
  各军种司令部   军区 / 边防司令部
        │
  人民卫队（国家安全机构，与 LVA 平行，见卷四）
```

### 1.3 四大军种

| 军种 | 原文名 | 职能 | 规模比重 |
|---|---|---|---|
| 陆军 | Landstreitkräfte | 核心力量：步兵、装甲、炮兵、工兵、防空兵 | 最大 |
| 空军 | Luftstreitkräfte | 以防空为主，构建多层次防空网 | 中等 |
| 海军 | Seestreitkräfte | 近海防御、反潜、岸防 | 较小 |
| 边防部队 | Grenztruppen | 守卫边境与铁墙，防止叛逃 | 独立建制 |

### 1.4 特色部队

- **黑隼突击队（Black Falcon Commandos）**：精锐特种部队，负责跨境秘密行动、反间谍与特种侦察，直属先锋党中央，是利西亚的威慑象征。内部使用非标准称号（突击队员 Sturmsoldat → 突击指挥官 Sturmführer）。
- **人民卫队（Volkswache）**：国家安全机构，与 LVA 平行，是社会控制工具（详见卷四）。

### 2.5 特殊军衔与标识

- **黑隼突击队**：内部用非标准称号（突击队员 → 突击指挥官）。
- **人民卫队**：军衔与 LVA 平行，名称前加"卫队"（如卫队少尉 Wacheleutnant、卫队上校）。
- **军衔标识**：
  - 士兵：红色肩章 + 金色条纹（列兵 1 条、上等兵 2 条、军士 3 条）。
  - 士官：红色肩章 + 银色齿轮（下士 1 个、中士 2 个、上士 3 个、军士长 4 个）。
  - 初级军官：深红肩章 + 金色黑隼徽章（少尉 1 只、中尉 2 只、上尉 3 只）。
  - 中级军官：深红肩章 + 银色星徽（少校 1 颗、中校 2 颗、上校 3 颗）。
  - 高级军官：金色肩章 + 黑隼与星徽（少将 1 颗、中将 2 颗、上将 3 颗、人民元帅为黑隼环绕金色麦穗）。
  - 海军：深蓝肩章，星徽替换为锚形图案。边防部队：绿色肩章。

## 九、卫国战争军事专题

### 9.1 战争概况

| 项目 | 内容 |
|---|---|
| 名称 | 卫国战争（Patriotic War） |
| 时间 | 2004 年 3 月 – 2008 年 9 月 |
| 参战方 | PRL + 诺瓦联盟 vs 利西亚联邦 + 西大陆合众国 |
| 主要战场 | 铁墙沿线、斯卡拉山脉、艾瑞斯海 |
| 结果 | 停火，维持战前边界，PRL 独立但损失严重 |

### 9.2 战争起因

- **意识形态对立**：南北利西亚长期对立，联邦支持反 PRL 地下运动。
- **资源争夺**：斯卡拉山脉铀矿/铁矿，艾瑞斯海渔业与港口。
- **边境冲突升级**：2004 年初铁墙沿线冲突不断，一名 PRL 边防士兵被联邦狙击手击毙，被宣传为"帝国主义侵略"。
- **外部干涉**：西大陆合众国与诺瓦联盟分别援助各自阵营。
- **导火索**：2004 年 3 月上旬，利西亚联邦特种部队潜入卡利斯托破坏"红星工厂"，致数十名工人死亡，PRL 宣布进入战争状态并宣战。

### 9.3 战争过程（军事层面）

- **初期（2004–2005）**：PRL 凭熊-III、黑隼-I 装甲部队在铁墙沿线取得局部优势，但未能突破联邦纵深防御。
- **中期（2006–2007）**：联邦凭猎鹰-15/16 的空中优势与艾瑞斯海海军封锁重创 PRL 经济，但无法深入内陆。双方在斯卡拉山脉与艾瑞斯海陷入拉锯。
- **终局（2008）**：2 月黑隼隘口血战（父亲维克多牺牲）；春末瓦伦堡遭轰炸（母亲艾琳娜牺牲）；9 月签署《艾瑞斯和平协定》。

### 9.4 战争后果（军事与战略）

- PRL 经济重创、物资配给更严、人民卫队权力扩大。
- 铁墙成为永久分界线，边境 100 公里内禁部署重型武器，设立联合监督委员会。
- 战争英雄（如维克多）被宣传为国家象征，塑造了一代人的忠诚与创伤。
