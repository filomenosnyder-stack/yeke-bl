## 第一部分　军队体制

### 一、军队总览

| 项目 | 内容 |
|---|---|
| 名称 | 利西亚人民军（Lycischer Volksarmee，简称 LVA） |
| 成立 | 1949 年，与共和国同期 |
| 性质 | 先锋党领导的社会主义工农军队 |
| 常备军规模 | 约 30 万 |
| 预备役规模 | 约 50 万（含民兵） |
| 最高统帅 | 总书记（名义）；实际由国防部与总参谋部指挥 |
| 政治属性 | 高度政治化，设政治委员制度，忠于先锋党（LPVP） |
| 兵役制度 | 义务兵役制为主，辅以志愿兵 |

#### 军队与党的关系

利西亚人民军从建军之日起就是"党的军队"。每个连队设政治委员（Politkommissar），负责思想教育、忠诚审查与士气维持。军事指挥与政治委员实行"双首长制"，重大行动须两人共同签署。人民卫队（国家安全机构）对军队内部实施忠诚监控，防止军事政变与叛逃。

#### 军队职能

1. **对外防御**：保卫领土、铁墙与主权，对抗利西亚联邦与西大陆合众国的军事压力。
2. **对内稳定**：协助人民卫队镇压动乱、维护"社会主义秩序"（官方表述）。
3. **威慑**：依托战术核武器与装甲力量，对敌方形成战略威慑。
4. **政治象征**：作为"工人阶级与农民"的武装，是政权合法性的重要支柱。

### 二、兵役制度

| 项目 | 内容 |
|---|---|
| 制度 | 义务兵役制（男子为主，女子可志愿） |
| 服役年龄 | 18 岁起 |
| 服役年限 | 陆军 2 年、空军 3 年、海军 3 年 |
| 征兵方式 | 地方兵役局按户籍征集，政治审查必过 |
| 豁免 | 独子、高校在读、关键岗位可减免 |
| 预备役 | 退役后编入预备役，定期集训 |

> 战时，国防委员会可宣布总动员，将预备役与民兵成建制转入现役。卫国战争期间（2004–2008）PRL 一度动员逾百万兵力。

### 三、指挥体系

```
总书记（最高统帅 / 国防委员会主席）
        │
   国防委员会（决策核心）
        │
   国防部 ──── 总参谋部（作战指挥）
        │         │
  各军种司令部   军区 / 边防司令部
        │         │
  师/旅/团 ─── 营/连/排/班
        │
   政治委员系统（思想与忠诚）
   人民卫队（内部监控，与 LVA 平行）
```

### 四、军事学说与战略方针

利西亚的军事学说立足于"**以弱抗强、守土为主、有限反击**"的现实：

1. **纵深防御**：依托斯卡拉山脉、铁墙与多层防空网，构建梯次防御，迟滞敌方进攻。
2. **装甲反击**：以熊-III、黑隼-I 装甲集群为拳头，在敌方突破后实施反击，恢复防线。
3. **防空优先**：空军以防空为主，构建"苍穹"系列导弹 + 高炮的多层防空网，保护工业城市与军事设施。
4. **近海拒止**：海军以近海防御、反潜、反舰游击战为主，利用冥河-2 反舰导弹实施"狼群"伏击。
5. **人民战争**：依托民兵、预备役与全民动员，进行长期消耗战。

## 第二部分　军种与部队

### 五、陆军（Landstreitkräfte）

陆军是利西亚人民军的核心力量，规模最大，承担主要作战任务。

| 兵种 | 职责 |
|---|---|
| 步兵 | 徒步与摩托化作战，坚守防线与阵地 |
| 装甲兵 | 坦克突击与反冲击 |
| 炮兵 | 火力压制、火力准备、纵深打击 |
| 工兵 | 架桥、布雷、破障、筑城 |
| 防空兵 | 野战防空，掩护部队与要地 |
| 通讯兵 | 通信保障与指挥自动化 |
| 防化兵 | 核化生防护与洗消 |
| 侦察兵 | 战场侦察与渗透 |

**陆军的核心编制**：装甲师、摩托化步兵师、步兵师、炮兵旅、防空旅、特种侦察营等。

### 六、空军（Luftstreitkräfte）

| 项目 | 内容 |
|---|---|
| 定位 | 以防空为主，兼顾对地支援 |
| 主力机型 | 鹰-29（制空）、鹳-25（对地攻击）、狐-24（轰炸）、鹤-76（运输）、蜻蜓-24（武直） |
| 防空体系 | 苍穹-6 / 苍穹-8 导弹 + 57mm 高炮，构成高中低空多层防空网 |
| 指挥 | 国土防空司令部统一指挥，雷达网 + 指挥所 |

**特点**：空优能力相对有限，但防空网密集，地面防空火力强大。卫国战争中，利西亚空军在制空权争夺中处于劣势，但凭借地面防空网与联邦空军周旋。

### 七、海军（Seestreitkräfte）

| 项目 | 内容 |
|---|---|
| 定位 | 近海防御、反潜、反舰、岸防 |
| 主力舰艇 | 海隼级护卫舰、鲟级潜艇、云隼级导弹艇 |
| 岸防 | 130mm 海岸炮、冥河-2 岸舰导弹 |
| 基地 | 艾瑞斯港（唯一主基地） |
| 海军陆战队 | 负责沿海要塞防御 |

**特点**：规模较小，近海游击战与伏击战见长，海权明显弱于利西亚联邦。艾瑞斯海是两国海军对峙的核心海域。

### 八、边防部队（Grenztruppen）

| 项目 | 内容 |
|---|---|
| 定位 | 守卫边境与铁墙，防止非法越境与叛逃 |
| 装备 | 轻武器、山隼式装甲车、边防巡逻艇、电子监控系统 |
| 部署 | 沿铁墙一线与北部边境部署，是叛逃防控的第一道屏障 |
| 性质 | 独立建制，与人民卫队密切配合 |

> 边防部队是铁墙的直接守卫者，也是"叛逃潮"中最前线、最敏感的一支部队。

### 九、黑隼突击队（Black Falcon Commandos）

利西亚最精锐的特种部队，是国家的威慑象征。

| 项目 | 内容 |
|---|---|
| 隶属 | 直属先锋党中央（不经常规指挥链） |
| 职能 | 跨境秘密行动、反间谍、特种侦察、要员保护、反恐 |
| 选拔 | 从全军挑选最忠诚、最强悍的士兵，通过极限考核 |
| 称号 | 内部使用非标准称号（突击队员 Sturmsoldat → 突击指挥官 Sturmführer） |
| 装备 | 最精良的轻武器、夜视仪、跳伞与潜水装备、加密通讯 |
| 象征 | 以黑隼为徽，与国徽、军徽一脉相承 |

> 黑隼突击队常与人民卫队特别行动局协同，执行不可公开的灰色任务，是政权最锋利的"黑刃"。

## 第五部分　军工产业

### 十三、军工体系

| 项目 | 内容 |
|---|---|
| 名称 | 人民军工（Volksarmament） |
| 隶属 | 国防工业委员会 |
| 核心企业 | 红星工厂（坦克/重型机械）、海隼造船厂（舰艇）、黑隼兵工厂（轻武器） |
| 主要产品 | 黑隼-I 坦克、海隼级护卫舰、云隼级导弹艇、山隼式装甲车、VK 系列轻武器（许可证） |
| 研发模式 | 与诺瓦联邦技术共享，关键领域力求国产化 |
| 资源支撑 | 斯卡拉山脉铁/煤/铀矿，黑隼山州铀矿为核计划核心（绝密） |

#### 军工特点

1. **重工业优先**：坦克、火炮、舰艇等重装备优先发展。
2. **轻工业滞后**：消费电子与精密仪器依赖进口/仿制，落后于联邦。
3. **核计划**：铀矿自给，核电站与核武器并举，高度保密。
4. **诺瓦依赖**：先进发动机、航电、导弹部分依赖诺瓦联邦，是"自力更生"与"受制于人"的矛盾所在。
