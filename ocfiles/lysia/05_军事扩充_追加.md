## 第十部分　弹药与弹道详解

### 三十、弹种机理与威力

#### APFSDS（尾翼稳定脱壳穿甲弹）

| 项目 | 内容 |
|---|---|
| 全称 | 尾翼稳定脱壳穿甲弹（Armor-Piercing Fin-Stabilized Discarding Sabot） |
| 弹芯材料 | 钨合金（利西亚与诺瓦技术，非贫铀） |
| 弹芯长径比 | 约 15:1 |
| 穿甲机理 | 高密度细长弹芯以极高动能撞击装甲，形成穿甲 |
| 初速 | 熊-III 125mm 主炮约 1715 m/s |
| 穿深 | 2000m 距离约 480–500mm 均质钢 |
| 特点 | 对现代复合装甲与反应装甲穿透力最强 |

#### HEAT（破甲弹）

| 项目 | 内容 |
|---|---|
| 全称 | 高爆反坦克破甲弹（High-Explosive Anti-Tank） |
| 破甲机理 | 装药爆炸产生金属射流，穿透装甲 |
| 破甲深度 | 熊-III 125mm 破甲弹垂直破甲约 550mm |
| 特点 | 破甲深度不受射程影响，但易受反应装甲与栅栏装甲干扰 |

#### HE-FRAG（杀伤榴弹）

| 项目 | 内容 |
|---|---|
| 全称 | 高爆破片杀伤弹 |
| 装药 | 约 7kg 高爆炸药 |
| 杀伤方式 | 爆炸冲击波 + 高速破片 |
| 用途 | 打击步兵、轻装甲、工事与建筑物 |

### 三十一、支援与轻装备

#### 82mm 迫击炮

| 参数 | 数值 |
|---|---|
| 口径 | 82mm |
| 弹重 | 约 3.1kg |
| 最大射程 | 约 3km |
| 射速 | 15–20 发/分 |
| 用途 | 营连级伴随火力，曲射打击掩体后目标 |

#### 手榴弹

| 类型 | 用途 | 威力 |
|---|---|---|
| 进攻型 | 冲击波杀伤，破片少，便于突进 | 杀伤半径约 5m |
| 防御型 | 大量破片，用于阵地防御 | 杀伤半径约 15–20m |

#### 地雷

| 类型 | 用途 | 威力 |
|---|---|---|
| 反步兵地雷 | 杀伤步兵，迟滞进攻 | 破片或爆破型 |
| 反坦克地雷 | 破坏坦克履带与车底 | 装药 5–10kg |

#### 侦察无人机（早期型号）

- 利西亚与诺瓦技术，用于战场侦察与炮兵校射，航程短、数量少，是"落后于联邦"的领域之一。

#### 火焰喷射器

- 用于清除堑壕、碉堡与地下工事，射程约 30–40m。

## 第十二部分　军事法规与纪律

### 三十三、军事刑法（节选）

| 罪名 | 处罚 |
|---|---|
| 叛逃罪（Hochverrat） | 最高死刑 |
| 临阵脱逃 | 死刑或长期监禁 |
| 违抗命令 | 军法审判，严重者死刑 |
| 泄露军事机密 | 重刑 |
| 破坏武器装备 | 军事监禁 |

> 战时军法从重从快，军事法庭与人民卫队忠诚监察组对军队实施双重监控。叛逃是军队与边防部队最敏感的问题。

## 第十三部分　军事情报体系

### 三十四、情报机构与协同

| 机构 | 职能 |
|---|---|
| 总参谋部军事情报局 | 战场侦察、敌情研判、战略情报 |
| 人民卫队对外情报局 | 境外谍报、双重间谍、虚假信息（见卷四） |
| 人民卫队反间谍局 | 反间、内部叛变调查（娜塔莉娅所属） |
| 技术与监听局 | 信号情报、监听、密码破译 |

> 军事情报局与人民卫队情报系统存在职能交叉与竞争，两者既协作又彼此防备，是体制内部的暗流之一。

### 三十五、情报手段

- **人力情报（HUMINT）**：线人网络、叛逃者、双重间谍。
- **信号情报（SIGINT）**：监听站、信号拦截器。
- **图像情报**：侦察卫星（少量）、侦察机、侦察无人机。
- **公开来源**：监听联邦广播、报纸，分析对方动态。

## 第十六部分　边防与叛逃防控

### 四十、铁墙边防体系

| 设施 | 说明 |
|---|---|
| 铁墙主体 | 高约 3.5m，顶部带刺网与电子感应 |
| 瞭望塔 | 沿墙密布，配探照灯与机枪 |
| 隔离带 | 墙两侧各 100m 开阔地，布设地雷与拒马 |
| 巡逻道 | 边防部队与警犬巡逻 |
| 电子监控 | 震动感应器、红外摄像、监听 |

### 四十一、叛逃防控

| 项目 | 内容 |
|---|---|
| 叛逃途径 | 翻越铁墙、越境、叛逃联邦 |
| 反叛逃措施 | 边防拦截、人民卫队监控、家属连坐式审查 |
| 叛逃后果 | 叛逃者家属受牵连，本人被判叛国罪 |
| 统计 | 铁墙沿线每年均有叛逃事件，是政权安全焦虑的根源 |

> 边防部队与人民卫队国内安全局共同负责叛逃防控，是铁墙最前线、最敏感的职能。
